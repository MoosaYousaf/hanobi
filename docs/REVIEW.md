# Whole-codebase review follow-up

The four saved review reports were recovered and checked against the current files. The two unfinished fixes in the working tree were preserved and completed. This covers the reports' reproducible findings and the requested suggestion layout; a review cannot guarantee the absence of other defects.

| Area | Changes |
| --- | --- |
| Local model data | Startup cleanup removes only the obsolete Whisper directory. Removing split models removes all shards and partial files, including older downloads without a shard manifest. Library size reflects the full model. |
| Local engine | Source is pinned to commit `5f490d7bfe78844e6390c869454c149fd7e003a8` and SHA-256 checked before extraction. Concurrent starts share one server; changing models during another active reply fails safely. Install cancellation aborts downloads and build commands. |
| Git | Automatic calls disable fsmonitor and hooks. Diffs disable external diff programs and text conversion. Checkpoints disable clean, smudge, and process filters, preserve the real index, and decline files over 25 MiB or repositories over 100 MiB. |
| Permissions | API tool access cannot become unrestricted CLI access during provider changes, including repeated Overseer switches. Claude Ask first explicitly requests its default permission mode. Persistent tool approvals are scoped by connection and server. Approval buttons no longer take focus from typing. |
| Stop and shutdown | Stop resolves pending tool approvals and questions and prevents subsequent connector calls. CLI processes are tracked and terminated; optional helper requests are aborted on quit. A truncated JSON fragment after Stop is not saved as assistant text. |
| MCP | Claude receives a private temporary config file rather than credentials in process arguments. Files are removed after completion. OAuth callback listeners, timers, and temporary clients close on success and failure. Blank edited secrets use trimmed key names. |
| Suggestions | Claude connections use Haiku. Native Claude suggestions and their forced quota-guard override are disabled. Copilot and local models skip helper requests. Other providers keep their model. Claude helper requests exclude MCP tools and user settings and use a short system prompt. Gemini helpers no longer resume a nonexistent session. Saved suggestions are capped at three; full chips that do not fit in one line are hidden and cannot receive keyboard focus. |
| Renderer and IPC | IPC accepts only the registered application's main frame; terminal actions also validate ownership. PDF printing uses an isolated session that blocks local and remote resources. Run windows blocks non-HTTPS requests and literal loopback/private addresses and cannot open external browser tabs. Script and executable file actions reveal the file in Finder. |
| Saved state | Secrets and conversation data use private, fsynced atomic replacements. Damaged secrets are retained for recovery and produce a warning. Delayed store-write failures are caught. Workspace deletion removes conversation attachments and outputs. |
| Drafts and UI | Edit-and-send validates before rewinding history and keeps edited text on validation failure. Attachment drafts survive switching threads. Voice input finishes before sending and does not replace subsequent manual edits. Dialog requests queue; approval cards are removed after successful IPC. Project and system instructions save as they change. `/access` no longer references an undefined variable. Mermaid suppresses temporary error drawings. Project dotfiles can be listed and removed. Missing project-update patches are accepted, and failed terminal opens do not accumulate listeners. |
| Resource use | Text extraction and cached plain-text reads are bounded. Model catalogs validate field types and limit response size. Downloads validate resume ranges, reject excess bytes, recover stale complete partial files and HTTP 416, and remove partial files on cancellation. |
| Build and release | Development mode supervises its watcher. The macOS installer refuses to replace a running Orin or Hanobi and never closes active sessions. Release builds have read-only credentials, checkout does not persist a token, publishing runs in a separate job, actions are pinned by commit, and releases include SHA-256 sums. |
| Dependencies | Electron is pinned to 43.8.9, electron-builder to 26.18.0, and vulnerable minimatch 7–10 dependencies are overridden with 11.0.8. The complete npm audit, including development dependencies, reports zero known vulnerabilities. |

The renderer intentionally provides terminal and connector operations to the user. The original reports did not demonstrate an XSS path; the IPC sender check is defense in depth and does not make arbitrary JavaScript in the trusted renderer harmless. The full-tool scope of “Always allow” remains explicit in the button label; approvals no longer carry between providers.

The old claim that all Electron versions after 40 drop macOS 12 was incorrect. Electron's [breaking-change documentation](https://www.electronjs.org/docs/latest/breaking-changes#removed-macos-12-support) places that removal at version 44. Electron 43.8.9 passed the complete app smoke test on this Mac's macOS 12.7.6 before installation. A future major update requires revisiting the OS support policy.

The archive checksum deliberately fails closed if GitHub regenerates different archive bytes. Updating it requires verifying the pinned source again.

Validation uses fake model servers and CLIs; no paid model-account requests are made. The test suite covers interrupted approvals, access-mode provenance, private MCP configuration, corrupted secret recovery, hostile Git filters, bounded extraction, invalid download ranges, split-file cleanup, concurrent engine startup, source integrity, and installation cancellation. The Electron smoke suite covers the full UI, narrow and widened suggestion rows, loopback and popup blocking, PDF network/file isolation, and the real terminal integration. GitHub Actions publishing and a full llama.cpp compiler build are not executed by these checks.

Final verification: 76 tests passed; the full Electron smoke suite passed on Electron 43.8.9 and macOS 12.7.6; `npm audit --json` reported zero known vulnerabilities. Light and dark UI screenshots were also inspected during layout verification.
